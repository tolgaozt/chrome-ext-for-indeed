Data points scraped from the Right-Hand Details Panel (after clicking a job card):

    Position Name
        Selector: h2[data-testid="simpler-jobTitle"]
        Method: .innerText

    Company
        Selector: div[data-testid="simpler-simplified-header"] a.jobsearch-JobInfoHeader-companyNameLink
        Method: .innerText (Handle potential null if link is missing)

    Location
        Selector: div[data-testid="jobsearch-JobInfoHeader-companyLocation"]
        Method: .innerText

    Salary
        Selector: div[aria-label="Salaire"] li[data-testid="list-item"] span
        Method: .innerText (Handle potential null if salary is missing)

    Job Type
        Selector: div[aria-label="Type de poste"] li[data-testid="list-item"] span
        Method: querySelectorAll, loop over results, get .innerText, join results with , (Handle empty list)

    Shift & Schedule
        Selector: div[aria-label="Horaires de travail"] li[data-testid="list-item"] span
        Method: querySelectorAll, loop over results, get .innerText, join results with , (Handle empty list)

    Education_Level
        Selector: div[aria-label="Formation"] li[data-testid="list-item"] span
        Method: querySelectorAll, loop over results, get .innerText, join results with , (Handle empty list)

    Skills
        Selector: div[aria-label="Compétences"] li[data-testid='list-item'] span
        Method: querySelectorAll, loop over results, get .innerText, join results with , (Handle empty list)

    Description
        Selector: #jobDescriptionText
        Method: .innerHTML (to preserve formatting, fallback to .innerText if preferred) (Handle potential null)

    External_Apply_Link (Direct external link, if found)
        Selector: (None - Accessed via JS)
        Method: Access window._initialData.hostQueryExecutionResult?.data?.jobData?.results?.[0]?.job?.url. Validate it's not an indeed.com URL. If valid external, use it, otherwise leave column empty.

    Indeed_Apply_Start_Link (Indeed's intermediate apply link)
        Selector: #applyButtonLinkContainer button[href]
        Method: .getAttribute('href') (Handle potential null if button/href is missing)

Data points captured/constructed based on clicking the Left-Hand List Card:
    ID (Job Key)
        Selector (for click listener): div[data-testid="slider_item"]
        Selector (to find element with ID within listener): [data-jk] (e.g., event.currentTarget.querySelector('[data-jk]'))
        Method: .getAttribute('data-jk') (Capture from the clicked card's child)

    Indeed_View_Job_Link
        Selector: (None - Constructed)
        Method: Construct string https://fr.indeed.com/viewjob?jk=${ID} using the captured ID.

Data point generated by the script:
    Scraped At
        Selector: (None - Generated)
        Method: new Date().toISOString()
