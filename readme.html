Indeed Scraper (Manual Click) - README

Purpose

This Chrome/Brave extension allows you to scrape job details from an Indeed job search results page. It works by requiring you to manually click on each job listing you want to capture. The details are then extracted from the right-hand panel that appears, stored locally, and can be downloaded as a CSV file.

Setup / Installation

  1. Ensure all the extension files (`manifest.json`, `popup.html`, `popup.js`, `content.js`, `background.js`, `bg.png`, and the `icons` folder) are together in one main folder (e.g., `indeed-scraper-extension`).
  2. Open your Chrome or Brave browser and navigate to the Extensions page:
    • Chrome: chrome://extensions
    • Brave: brave://extensions
  3. Enable Developer mode using the toggle switch (usually in the top-right corner).
  4. Click the "Load unpacked" button.
  5. Navigate to and select the main folder containing the extension files (e.g., `indeed-scraper-extension`).
  6. The extension icon should appear in your browser's toolbar.

How to Use

  1. Navigate to an Indeed job search results page (e.g., https://fr.indeed.com/jobs?q=...&l=...).
  2. Click the extension's icon in your browser toolbar to open the popup window.
  3. Click the "Start Scraping" button in the popup. The status text should change to "Scraping active...".
  4. Manually click on the first job card you want to scrape from the left-hand list on the Indeed page. Click the main body of the card (the `div[data-testid="slider_item"]`), not necessarily the job title link itself.
  5. Wait for the job details panel on the right-hand side to fully load/update. The extension automatically scrapes the data in the background shortly after the panel updates. (Check the DevTools console for logs if needed).
  6. Repeat steps 4 & 5: Click the next job card on the left, wait for the right panel to update. Continue for all jobs you want on the current page.
  7. If you want jobs from the next page of Indeed results, manually navigate to the next page using Indeed's pagination buttons.
  8. Repeat the clicking process (steps 4-6) for the jobs on the new page. The extension will keep adding unique jobs to its stored list.
  9. When you have finished clicking all the jobs you want to scrape (for this session or overall), you can optionally click the "Stop Scraping" button in the popup. This stops the extension from listening for further clicks. You can restart it later.
  10. Click the "Download Jobs (CSV)" button in the popup. A "Save As" dialog will appear, allowing you to save the collected job data as a CSV file (e.g., `indeed_jobs_YYYYMMDDHHMMSS.csv`).
  11. The "Clear Stored Jobs" button will permanently delete all job data stored by the extension within your browser. Use this with caution, as the data cannot be recovered!

Output CSV Columns Explained

  • Position Name: The job title.
  • Company: The hiring company's name.
  • Location: The job location text.
  • Salary: Salary information, if available (often empty).
  • Job Type: Type(s) of employment (e.g., "CDI, Temps plein"), comma-separated if multiple.
  • Shift & Schedule: Work hours/schedule details, comma-separated if multiple.
  • Education_Level: Required education levels, comma-separated if multiple.
  • Skills: Listed skills, comma-separated if multiple.
  • Description: The full job description text, including HTML formatting (e.g., paragraphs, lists).
  • ID: The unique Indeed Job Key (e.g., d1b7dbf7c8a63b20).
  • Indeed_View_Job_Link: The standard URL to view this job directly on Indeed. Always generated if an ID is found.
  • External_Apply_Link: Populated ONLY if a direct external application link (e.g., to jobaffinity.fr, company ATS) was found embedded in the page's JavaScript data. Often empty.
  • Indeed_Apply_Start_Link: Populated ONLY if the apply button was the "Continuer pour postuler" type, linking to an Indeed `/applystart?...` URL. Often empty.
  • Scraped At: The date and time (ISO format, UTC) when the specific job's details were scraped.

Note: Some fields (like Salary, Education, and the specific apply links) might be empty if the information wasn't present on the Indeed listing.

Notes & Troubleshooting

  • If the extension stops working (e.g., doesn't scrape after clicking), try reloading the extension from the chrome://extensions page.
  • If Indeed significantly changes its website structure, the CSS selectors used by this extension may break, requiring updates to the content.js file.
  • This extension relies entirely on manual clicks to trigger scraping; it does not automatically navigate pages or click jobs.
  • Scraped data is stored locally within your browser's extension storage. Clearing your browser data or removing the extension may delete the stored jobs. Use the "Clear Stored Jobs" button for explicit removal.
